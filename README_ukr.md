## Огляд

[Steroid Cycle Plotter] — це веб-застосунок для планування, візуалізації та аналізу курсів стероїдів. Інструмент моделює фармакокінетику різних стероїдних ефірів, відображаючи криві концентрації в залежності від дозування, періоду напіввиведення, інтервалів прийому та тривалості циклу. Підтримує одночасну роботу з кількома сполуками та індивідуальне налаштування фармакокінетичних коефіцієнтів.

## Особливості

- Включає популярні стероїдні ефіри: Testosterone Propionate, Enanthate, Nandrolone Decanoate, Trenbolone Acetate, HCG та режим Custom.
- Інтерактивна форма для додавання сполук з можливістю налаштування дози, періоду напіввиведення, інтервалу дозування, тривалості циклу та зсуву початку.
- Індивідуальне управління множниками всмоктування (kaMultiplier), виведення (keModifier) та концентрації для кожної сполуки.
- Можливість об’єднувати всі сполуки в одну сумарну криву концентрації з урахуванням індивідуальних множників.
- Динамічний, масштабований, інтерактивний графік концентрації на основі Chartjs.
- Імпорт та експорт протоколів у форматі JSON з повним збереженням параметрів сполук.
- Адаптивний інтерфейс з валідацією та дружніми повідомленнями.

## Використання

1. Відкрийте `index.html` у сучасному браузері з підтримкою JavaScript.
2. Виберіть дату початку циклу.
3. Додайте сполуки через форму, встановлюючи дозу, період напіввиведення, інтервал дозування, тривалість циклу та зсув початку.
4. Натисніть **Add Compound** для додавання або **Update Compound** для редагування сполуки.
5. Вмикайте або вимикайте комбінування сполук на графіку через чекбокс.
6. Експортуйте протокол у JSON або імпортуйте його для відновлення збережених циклів.
7. Використовуйте кнопки для оновлення або скидання масштабу графіку.

## Фармакокінетична модель

### Константа виведення (kₑ)

Ця константа характеризує швидкість виведення препарату з організму. Вона розраховується як відношення натурального логарифму числа 2 (приблизно 0.693) до періоду напіввиведення препарату (час, за який концентрація препарату зменшується наполовину), помножене на коефіцієнт модифікації швидкості виведення для кожної сполуки.

\[
k_e = \left(\frac{\text{натуральний логарифм 2}}{\text{період напіввиведення}}\right) \times keModifier
\]

- *Натуральний логарифм 2* (~0.693) відображає суть напівжиття препарату.
- *Період напіввиведення* — час, за який концентрація препарату зменшується наполовину.
- *keModifier* — індивідуальний коефіцієнт налаштування швидкості виведення.

### Константа всмоктування (kₐ)

Ця константа визначає швидкість всмоктування препарату у кровотік. Вона обчислюється множенням константи виведення \(k_e\) на множник всмоктування для кожної сполуки.

\[
k_a = k_e \times kaMultiplier
\]

- \(k_e\) — константа виведення, описана вище.
- *kaMultiplier* — коефіцієнт, що регулює швидкість всмоктування препарату.

Ці константи визначають фармакокінетичний профіль, балансуючи швидкість входження і виведення препарату, що забезпечує точність моделювання концентрації в часі.

## Технічні деталі

- Використання Chartjs для інтерактивних анімованих графіків.
- Клієнтський JavaScript, без серверної частини.
- Формат імпорту/експорту JSON підтримує повне збереження параметрів.
- Інтерфейс підтримує список сполук з функціями редагування і видалення.

## Важливі зауваження

- Інструмент базується на спрощеній моделі фармакокінетики з приблизними параметрами.
- Не є медичною рекомендацією; перед змінами у протоколах консультуйтесь із лікарем.
- Параметри можна налаштовувати для симуляції різних сценаріїв, але результати є орієнтовними.
